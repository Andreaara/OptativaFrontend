# OptativaFrontend — Sistema de Gestión y Facturación

Aplicación web desarrollada en React y Vite para la administración de facturación electrónica, gestión de emisores, receptores, categorías, impuestos, pagos, usuarios y logs de auditoría. Se conecta mediante API REST (AWS API Gateway) a servicios respaldados por MySQL (RDS) y DynamoDB.

## Requisitos previos
- Node.js (v18 o superior)
- npm
